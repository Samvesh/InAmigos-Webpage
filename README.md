# 🌍 InAmigos Foundation NGO Awareness Website

A modern and responsive NGO awareness webpage created for **InAmigos Foundation** using **HTML** and **CSS**.
This project was designed to spread awareness about social initiatives, community programs, volunteer campaigns, and youth-driven impact activities through a clean and aesthetic web experience.

---

## ✨ Features

* Modern responsive UI design
* Fully structured single-page layout
* Hero section with impactful visuals
* About section highlighting NGO mission
* Ongoing projects showcase
* Social impact statistics section
* Interactive gallery section
* Call-to-action for volunteering and support
* Clean animations, hover effects, and gradients
* Mobile responsive design

---

## 🛠️ Technologies Used

* HTML5
* CSS3
* Google Fonts
* Font Awesome Icons

---

## 📌 Sections Included

* Home / Hero Section
* About NGO
* Ongoing Projects
* Social Impact Statistics
* Gallery
* Volunteer & Support CTA
* Footer with Social Links

---

## 🎯 Objective

The goal of this project is to create awareness about NGO initiatives and encourage people to participate in community-driven change through volunteering, donations, and social campaigns.
